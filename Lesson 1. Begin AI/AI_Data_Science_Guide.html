Модуль 1: Основи штучного інтелекту та науки про дані

1.1 Історія розвитку штучного інтелекту

Штучний інтелект (ШІ) — одна з найдинамічніших галузей комп'ютерних наук. Його історія налічує понад 70 років:

  • 1950-1960-ті роки (Заснування): Дартмутська конференція (1956) офіційно створила галузь ШІ. Ранні системи могли розв'язувати простенькі логічні завдання.
  • 1966-1974 роки (Перша зима ШІ): Гіпотези було переоцінено, фінансування скоротилось.
  • 1980-1987 роки (Бум експертних систем): Системи, які кодували знання експертів, знайшли практичне застосування.
  • 1987-1993 роки (Друга зима ШІ): Експертні системи не виправдали очікувань.
  • 1993-2011 роки (Статистичні методи): Зростання обчислювальних потужностей дозволило нейромережам повернутись. Deep Blue переміг Каспарова в шахах (1997).
  • 2011-дотепер (Глибоке навчання та Big Data): Революція глибоких нейромереж. AlphaGo перемагає в Го (2016). ChatGPT запущено (2022).

1.2 Поняття штучного інтелекту

Штучний інтелект (ШІ) — це галузь комп'ютерних наук, спрямована на створення систем, здатних виконувати завдання, які зазвичай потребують людської розумової діяльності.

Основні характеристики ШІ:

  • Розпізнавання образів та мови
  • Прийняття рішень на основі даних
  • Обробка природної мови
  • Навчання на основі досвіду
  • Адаптація до нових ситуацій

Рівні ШІ:

Рівень Опис
Слабий ШІ Система, розроблена для вирішення конкретного завдання. Більшість існуючих ШІ систем — це слабкий ШІ.
Сильний ШІ Гіпотетична система з людськими когнітивними здібностями. Може переносити знання між завданнями.
Надлюдський ШІ Це матеріал науково-фантастичних творів, поки що не існує.

1.3 Поняття науки про дані

Наука про дані (Data Science) — міждисциплінарна галузь, яка поєднує статистику, програмування та предметні знання для вилучення цінних висновків з даних.

Компоненти науки про дані:

  • Збирання даних
  • Очищення та підготовка
  • Дослідницький аналіз
  • Моделювання та прогнозування
  • Комунікація результатів

1.4 Поняття машинного навчання

Машинне навчання (Machine Learning, ML) — підгалузь ШІ, яка дозволяє системам навчатись і поліпшуватись на основі даних без явного програмування.

Основна ідея: замість того, щоб запрограмувати правила явно, ми навчаємо алгоритм розпізнавати закономірності в даних.

Приклад: замість написання правил для розпізнавання котів, ми показуємо алгоритму тисячі картинок котів, і він вчиться розпізнавати їх самостійно.

Модуль 2: Artificial Intelligence та Machine Learning

2.1 Що таке Artificial Intelligence?

Artificial Intelligence (AI) — це широка галузь, орієнтована на створення систем, здатних виконувати завдання, які потребують розуму:

  • Розробка роботів
  • Обробка природної мови (NLP)
  • Комп'ютерний зір
  • Рекомендаційні системи
  • Машинне навчання

2.2 Що таке Machine Learning?

Machine Learning — це підмножина AI, яка зосереджена на алгоритмах, що навчаються на даних.

ML систем не потрібно явно програмувати для кожного сценарію — вони вивчають закономірності та адаптуються.

2.3 Відмінність AI та ML

Аспект AI ML
Галузь Широка галузь Підгалузь AI
Підхід Може включати явне програмування Навчання з даних
Приклад Шахові алгоритми, чат-боти Розпізнання образів, прогноз
Гнучкість Більш жорсткі правила Адаптується до нових даних

Модуль 3: Види алгоритмів і сфери їхнього застосування

3.1 Навчання з учителем (Supervised Learning)

Алгоритми навчаються на основі помічених даних — кожен вхід має відповідний правильний вихід.

Характеристика: потребує великої кількості помічених прикладів для навчання.

Два основних типи завдань:

  • Регресія: передбачення неперервного значення (напр., ціна дому)
  • Класифікація: категоризація на класи (напр., спам або не спам)

Приклади алгоритмів:

  • Лінійна регресія
  • Логістична регресія
  • Дерева рішень
  • Випадкові ліси
  • Метод опорних векторів (SVM)

Сфери застосування:

  • Медицина: діагностика хвороб
  • Фінанси: оцінка кредитного ризику
  • E-commerce: рекомендація товарів
  • Розпізнання образів і тексту

3.2 Навчання без учителя (Unsupervised Learning)

Алгоритми працюють з непомічені даними, шукаючи приховані закономірності та структури.

Характеристика: алгоритм повинен самостійно виявити цікаві закономірності.

Два основних типи завдань:

  • Кластеризація: групування подібних об'єктів
  • Зниження розмірності: скорочення кількості ознак

Приклади алгоритмів:

  • K-means кластеризація
  • Ієрархічна кластеризація
  • Аналіз головних компонент (PCA)
  • DBSCAN

Сфери застосування:

  • Сегментація клієнтів
  • Виявлення аномалій
  • Стиснення даних
  • Вивчення структури даних

3.3 Навчання з підкріпленням (Reinforcement Learning)

Агент навчається через взаємодію з середовищем, отримуючи награди або штрафи.

Характеристика: агент повинен знайти оптимальну стратегію дій для максимізації накопленої награди.

Ключові концепції:

  • Агент: система, яка приймає рішення
  • Середовище: світ, з яким взаємодіє агент
  • Дія: що робить агент
  • Награда: оцінка за дію
  • Політика: стратегія агента

Приклади алгоритмів:

  • Q-Learning
  • Policy Gradient
  • Actor-Critic методи

Сфери застосування:

  • Ігри (AlphaGo, гри для однієї особи)
  • Робототехніка
  • Автономні автомобілі
  • Управління ресурсами
  • Оптимізація маршрутів

Модуль 4: Датасети та ознаки

4.1 Поняття датасета

Датасет (Dataset) — набір даних, який використовується для навчання, валідації та тестування машинних моделей.

Датасет складається з рядків (спостережень) та стовпців (ознак/особливостей).

4.2 Приклад датасета

Приклад: Датасет ціни будинків

ID м² Кімнат Роки Паркинг Басейн Гараж Ціна ($)
1 120 3 5 Так Ні Так 250000
2 95 2 3 Ні Ні Ні 180000
3 150 4 8 Так Так Так 320000

4.3 Ознаки в датасеті

Ознаки (Features) — це окремі змінні або атрибути, які описують кожен об'єкт у датасеті.

У прикладі з будинками ознаками є:

  • Площа (м²)
  • Кількість кімнат
  • Вік будинку (роки)
  • Наявність паркингу
  • Наявність басейну
  • Наявність гаража

Типи ознак:

  • Числові (Numerical): площа, вік, кількість кімнат
  • Категоріальні (Categorical): наявність паркингу (Так/Ні)
  • Порядкові (Ordinal): рівень якості (низька, середня, висока)

4.4 Поняття цільової ознаки

Цільова ознака (Target Feature / Label) — це та ознака, яку ми хочемо передбачити з використанням інших ознак.

У прикладі з будинками — це стовпець "Ціна ($)".

Всі інші ознаки називаються "вхідними ознаками" (input features).

Модель навчається, щоб із заданих вхідних ознак передбачити цільову ознаку.

Модуль 5: Jupyter Notebook та Jupyter Lab

5.1 Що таке Jupyter Notebook?

Jupyter Notebook — це інтерактивне веб-середовище для написання та запуску коду, створення документацій та візуалізацій.

Це універсальний інструмент для дослідників, аналітиків даних та науковців.

Назва "Jupyter" розшифровується як Julia, Python та R — три мови програмування, які підтримуються.

5.2 Що таке Jupyter Lab?

Jupyter Lab — це нова версія Jupyter, яка надає більш розширене середовище розробки.

Переваги Jupyter Lab:

  • Багатовіконний інтерфейс
  • Краща керування файлами
  • Вбудовані термінали та текстові редактори
  • Розширення та плагіни
  • Темне та світле оформлення

5.3 Нотбуки та комірки

Notebook складається з комірок (cells). Комірки можуть містити:

  • Код (Code cells): код мовою Python (або іншою)
  • Текст (Markdown cells): форматований текст, заголовки, списки
  • Raw text: неформатований текст

Приклад структури нотбука:

  • Markdown комірка: Заголовок "Аналіз даних ціни будинків"
  • Code комірка: імпорт бібліотек
  • Code комірка: завантаження датасету
  • Code комірка: вивід статистики
  • Markdown комірка: висновки
